# 아버지와 딸의 기차역 픽업

실제 지명·GPS 대신 가상 역과 시뮬레이션 좌표를 사용하는 체험 시나리오입니다.

- 상황: 오랜만에 본가에 오는 딸을 아버지가 금요일 저녁에 마중
- 약속: 오후 7시 5분, 역 2번 출구 지정 승하차 구역
- 변수: 캐리어와 엘리베이터 대기로 딸이 늦게 나옴

| 순서 | 아버지 | 딸 | 앱 반응 |
| --- | --- | --- | --- |
| 1 | 픽업 링크 공유 | 장소·시간 확인 | 약속 확정 |
| 2 | 차량 화면에서 픽업 시작 | 출발·ETA 확인 | 경로 안내·위치 공유 |
| 3 | 역으로 접근 | 준비 중, 출발까지 5분 입력 | 준비 상태 안내 |
| 4 | 딸의 상태를 음성으로 질문 | 엘리베이터 대기 | 대기 장소 선택 지원 |
| 5 | 주차장에서 대기 | 나오는 중 선택 | 재접근 시점 제안 |
| 6 | 승하차 구역으로 이동 | 차량 접근 확인 | 위치·ETA 갱신 |
| 7 | 정차 완료 확인 | 차량 식별·탑승 | 탑승 지원 |
| 8 | 탑승 완료 확인 | 공유 종료 확인 | 위치 공유 중단·세션 종료 |

## 프로토타입 표시 원칙

- 차량·휴대폰 화면에 시뮬레이션임을 표시
- 실제 메시지·음성 명령·차량 제어를 실행한 것처럼 표현하지 않음
- 위치 근접이나 문 열림만으로 특정인의 탑승을 확정하지 않음
