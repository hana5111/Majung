# 서비스 기획

- 대상: 가족·친구·동료를 태우러 가는 일반 운전자와 탑승자
- 목표: 반복 연락·정차 대기·엇갈림을 줄이는 픽업 조율
- 운전자: Pleos 차량 앱을 가정한 웹 화면
- 탑승자: 초대 링크로 참여하는 모바일 웹

## 기본 흐름

| 단계 | 행동 | 불편 | 기능 후보 |
| --- | --- | --- | --- |
| 운행 전 | 초대하고 장소·시간 합의 | 모호한 출구와 약속 | 픽업 세션, 지도 핀·사진, 제안·수락 |
| 운행 중 | 픽업 시작·이동·준비 | 운전 중 반복 연락 | 내비 연결, 위치·ETA, 준비 상태, 음성 확인 |
| 만나기 직전 | 접근·대기·재접근 | 정차 곤란·시간 불일치 | 접근 방향 고려, 대기 장소, 시간 조율, 대체 지점 합의 |
| 탑승·종료 | 차량 식별·탑승 확인 | 차량 찾기·공유 종료 누락 | 정차 상태 안내, 사용자 완료 확인, 세션 만료 |

## 차량용 가치 강화 후보

- 차량 진입 경로와 탑승자 보행 경로를 함께 고려한 만남 지점
- 탑승 준비 지연 시 대기 및 재접근 안내
- 차량 상태에 따른 접근·정차·탑승 단계 구분
- 운전자 승인에 따른 차량 식별 조명·짐 적재 지원

## 검증 필요

- GPS 오차, 모바일 웹 백그라운드 위치·알림
- Gleo·내비게이션·차량 상태 및 제어 API 권한
- 지정 승하차·주차 데이터와 보행 경로 확보
- 실제 사용자의 연락 횟수·대기 시간·재사용 의사

위 기능은 기획 후보이며 지원이나 구현 완료를 의미하지 않습니다.
